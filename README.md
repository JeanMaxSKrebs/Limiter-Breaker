# Limiter Breaker

App de treinos inspirado no conceito de quebrar o limitador, com desafio de 3 anos baseado na rotina clássica: 100 flexões, 100 abdominais, 100 agachamentos e 10 km de corrida.

## Status

Este projeto começou como uma interface React + Vite gerada pelo Figma Make e foi convertido para uma base Expo/React Native.

## Telas atuais

- Home: progresso do desafio, data inicial/final, treino do dia e estatísticas rápidas.
- Workout: escolha entre treino completo, intercalado e super intercalado.
- Ranking: ranking por dias consecutivos ou exercícios totais.
- Friends: busca de amigos e progresso diário da equipe.

## Rodando no PC

Instale as dependências:

```bash
npm install
```

Inicie o Expo:

```bash
npm start
```

Para abrir no Android:

```bash
npm run android
```

Ou abra com o app Expo Go lendo o QR Code exibido no terminal.

## Observação

Os dados ainda são mockados no front-end. Login, banco de dados, ranking real e progresso persistente ainda precisam ser implementados.
